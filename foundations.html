Contrast of the pairings used in the designs

WCAG 2.2 contrast ratios. Body text needs 4.5:1 (AA); large text (24px+, or 18.66px+ bold) and UI parts need 3:1.

DoUse the semantic token for the job (for example surface/card for cream panels), not the raw hex.
Don'tDon't set small text in white on Tan or Light Gray on Emerald. Both fall below 4.5:1.

CSS

How the three layers connect in css/design_system.css.

:root {
  /* 1 · Primitive */
  --aa-forest-green: #003d20;
  --aa-emerald-green: #0a714e;

  /* 2 · Semantic token (alias) */
  --sds-action-primary: var(--aa-forest-green);
  --sds-action-primary-hover: var(--aa-emerald-green);
  --sds-surface-page: var(--aa-sand);

  /* 3 · Bootstrap mapping */
  --bs-primary: #003d20;
  --bs-body-bg: var(--sds-surface-page);
  --bs-link-color: var(--sds-text-link);
}

Usage notes

  • Use the existing artwork rather than redrawing it. Navigation glyphs use light gray on forest green; the mobile menu uses white.
  • Status glyphs use charcoal on yellow. The different icon sizes shown above are intentional sizes observed in the designs.
  • The three logo specimens show two navigation sizes and one footer treatment of the same brand mark.
